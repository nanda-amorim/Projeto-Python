# 📊 Análise de Dados de Vendas – E-commerce de Assinaturas

Este projeto consiste em um script Python desenvolvido para analisar o desempenho de vendas e o comportamento de clientes em um e-commerce baseado em modelos de assinatura

## 🚀 O que o Script Faz

* **Catálogo de Planos**: Mostra de forma organizada as opções de assinaturas disponíveis.
* **Painel de Mais Vendidos**: Exibe o comparativo de vendas entre os planos mensal, semestral e anual.
* **Sucesso por Região**: Aponta qual plano vende mais em cada estado do país.
* **Destaques de Faturamento**: Revela quais estados geram a maior receita para o negócio.
  
## 🛠️ Tecnologias Utilizadas

* **Python 3.13**: Versão atualizada da linguagem base do projeto.
* **Pandas**: Utilizada para organizar e analisar os dados de vendas.
* **Streamlit**: Utilizada para criar o painel visual e interativo (dashboard).

## 📦 Como Executar o Projeto

1. **Abra o terminal** na pasta do projeto.
2. **Instale as bibliotecas** necessárias:
   ```bash
   pip install pandas
   pip install streamlit
   ```
3. **Execute o comando run** do Streamlit para abrir o painel no seu navegador:
   ```bash
   streamlit run dados_venda.py
   ```
